# Zida Bruun — artist site

Black-and-white catalogue style with a yellow landing page, self-service
editing via Decap CMS + DecapBridge. No coding needed after setup.

`index.html` currently has the design content baked in directly (not yet
reading from the `content/` JSON files) while the design is being finalized.
`admin/` and `content/` are ready for when the CMS gets reconnected to it.

See prior setup notes for connecting GitHub → Netlify → DecapBridge.
Site is already live at https://zidabruun.netlify.app
